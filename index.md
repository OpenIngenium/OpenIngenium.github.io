<center>Root of Engineer (Latin) - Ingenium</center>


- Multi-Mission, Executable, Electronic Procedure System for System Level Integration and Test 
- Web application with rich user interface
    - Drag and drop, copy/paste, search and replace
- Common format across test venues and teams
  - Visually and electronically
- Replaces paper test procedures with executable electronic  procedure (that looks and feels like paper procedure)
- Directly interfaces with ground data system (GDS) to send commands and query telemetry.
- Removes manual interactions that drive execution time and errors.
- Provides much of the functionality of scripted procedures without any code.
- Integrates with project data sources such as command/telemetry dictionary and requirements
- Assists in procedure development
- Enforces procedure policy regarding tactical change management.
  - E.g. Redlines/Bluelines
